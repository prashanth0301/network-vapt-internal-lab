# Development Plan

---

# Version

# Development Methodology

The project follows an incremental phase-wise development methodology.

Every phase will include:

- Planning
- Development
- Testing
- Documentation
- Git Commit
- Screenshot Collection

Only after successfully completing one phase will development continue to the next.
